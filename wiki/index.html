Lenovo Legion Toolkit Documentation

Technical reference and user manual for Lenovo Legion Toolkit (LLT), an open-source desktop utility for Lenovo gaming laptops that runs without background services or telemetry.

System Requirements

  • Operating System: Windows 10 (version 19041 or higher) or Windows 11 (64-bit).
  • Architecture: x64 native.
  • Runtime: Microsoft .NET 9.0 Desktop Runtime.
  • Privileges: Administrative privileges required for hardware register and WMI access.
Required Drivers on Clean Windows Installs

If Windows was installed clean from official media, ensure the following drivers are installed from Lenovo Support so that hardware communication interfaces are active:

  1. Lenovo Energy Management (IBMPMDRV)
  2. Lenovo Vantage Gaming Feature Driver

Note: These two drivers are not required on Generation 10 and newer hardware.

Installation & Setup

Download the latest installer executable from GitHub Releases. The installer deploys the application and configures necessary dependencies.

Installing newer versions directly over an existing installation preserves all configured settings, custom fan presets, macros, and actions.

Recommended Configuration

Because the application does not install persistent Windows background services, it should remain active in the system tray to handle automated profile switching and hotkeys.

  • Open Settings -> App Behavior.
  • Enable Autorun (starts minimized on Windows login).
  • Enable Minimize on close (keeps the tray icon active when closing the main window).

Handling Lenovo Vantage

Running Lenovo Vantage alongside Lenovo Legion Toolkit can create hardware communication conflicts when both applications attempt to write to Embedded Controller (EC) registers simultaneously.

You do not need to uninstall Lenovo Vantage. The toolkit includes a built-in software disabler:

  1. Open Settings -> Software Control.
  2. Toggle Disable Lenovo Vantage and Lenovo Hotkeys.

This safely halts the background service components (Lenovo Vantage Service, System Interface Foundation) without deleting files. If you ever need Vantage, you can re-enable it from the same toggle.

Power Modes & Custom Tuning

Lenovo hardware exposes native power states that alter Embedded Controller thermal profiles and fan tables:

Internal State Display Name Hardware Value Description
Quiet Quiet 0 Lower power limits, prioritized low acoustic profile.
Balance Balance 1 Dynamic performance scaling according to system load.
Performance Performance 2 Maximum sustained clock speeds and aggressive fan curve (requires AC adapter).
Extreme Extreme 223 High thermal envelope profile available on select models.
GodMode Custom Mode 254 User-customized power thresholds, thermal ceilings, and fan tables.

Custom Mode Configuration

On laptops that support Custom Mode (GodMode), the application provides granular configuration of hardware limits:

  • CPU Long Term Power Limit (PL1): Sustained CPU power limit in watts.
  • CPU Short Term Power Limit (PL2): Boost power envelope for short bursts.
  • CPU Peak Power Limit (PL4): Instantaneous electrical burst ceiling.
  • CPU Temperature Limit: Thermal throttling ceiling for the processor.
  • GPU Configurable TGP: Target Graphics Power for discrete NVIDIA GPUs.
  • GPU Dynamic Boost: Additional cross-load wattage allocated from CPU to GPU under gaming workloads.

Battery & Charging Controls

Battery parameters communicate with the battery charge controller through ACPI and driver interfaces.

Conservation Mode

Limits maximum battery charge percentage to reduce degradation when connected to AC power for extended durations.

  • 2021 and earlier models: Firmware threshold is fixed at 60%.
  • 2022 and later models: Firmware threshold is fixed at 80%.
Firmware Threshold Limitation

The Conservation Mode threshold percentage is hardcoded in the laptop Embedded Controller (EC) firmware. It cannot be altered by software on standard Legion and LOQ models.

Additional Charging Features

  • Rapid Charge: Accelerates charging rate to reach high capacity quickly. Mutually exclusive with Conservation Mode.
  • Night Charge: Slows charge rate overnight to reduce heat generation during charging cycles.
  • Dual Thresholds: On ThinkBook and enterprise-aligned devices supporting the PWRMGRV interface, customizable Charge Start and Charge Stop percentages are exposed.

Custom Fan Curves

Custom fan table control is available in Custom Mode on Generation 7 (2022) and newer laptops whose firmware exposes fan table registers.

  • 10-Point Fan Table: Configure fan speeds across temperature steps for CPU and GPU sensors.
  • Full Fan Speed Mode: Overrides active curves to immediately drive fans to 100% capacity.
Hardware Support Notice

Custom fan curves cannot be applied to Quiet, Balance, or Performance modes, as those profiles use immutable firmware fan tables stored in the BIOS. Fan control is not available on Generation 6 (2021) and older models due to lack of EC register support.

GPU Operating Modes & Display

Controls the hardware multiplexer (MUX) and discrete GPU power states:

  • dGPU Only: Internal display connects directly to the discrete GPU for lowest latency. Requires system restart to change.
  • Hybrid: Internal display connects to the integrated GPU. Discrete GPU powers down when idle to conserve battery.
  • Hybrid iGPU-Only (Gen 7 and newer): Disconnects the discrete GPU electrically from the bus to eliminate any possibility of background power draw on battery.
  • Hybrid Auto: Automatically engages Hybrid iGPU-Only mode on battery power and reconnects the dGPU when connected to AC power.
  • UMA Mode: Dedicated iGPU operation mode supported on select AMD configurations.

Display Controls

  • Refresh Rate: Toggle between high refresh rates (165Hz, 240Hz) and battery-saving refresh rates (60Hz).
  • Display Overdrive: Lowers panel response times to eliminate ghosting during high framerate gaming.
  • Auto Color Management: Toggles Windows Auto Color Management (ACM) on compatible HDR displays.

Keyboard & RGB Lighting

The application interfaces natively with keyboard controllers without requiring Corsair iCue or Vantage:

  • Spectrum Per-Key RGB: Configure individual key colors, brightness levels, and hardware presets.
  • 4-Zone RGB: Configure color assignments and effects across 4 keyboard zones.
  • Chassis Lighting: Manage rear port illumination and lid panel logo lighting.
  • White Backlit Keyboards: Manage 1-level and 3-level white keyboard backlights.
  • Windows Dynamic Lighting: Exposes keyboard hardware to Windows 11 Dynamic Lighting (LampArray API).

Actions & Automation Triggers

Actions allow running automated configuration sequences when system events occur:

  • Power State: AC adapter connected, AC adapter disconnected, low-wattage USB-C charger detected.
  • Battery State: Charge percentage drops below or rises above specified values.
  • Lid & Display: Laptop lid opened or closed; external display connected or disconnected.
  • Network State: Connected or disconnected from specified Wi-Fi SSID.
  • Process & Gaming: Detects when a game starts or closes (via GPU activity, Xbox Game Bar GameConfigStore, or Windows Game Mode).
  • Time Schedule: Sunrise, sunset, fixed time, or periodic execution intervals.

Command Line Interface (llt.exe)

The CLI utility is located in the installation directory as llt.exe. It allows controlling toolkit functions via scripts, batch files, or terminal shortcuts.

For the CLI to function, the main application must be running in the background, and CLI support must be enabled in Settings -> Integrations.

# List all available hardware features llt feature --list # Read current power mode llt feature get power-mode # Set power mode to Performance llt feature set power-mode performance # Set 4-zone RGB preset llt rgb set 1 # Execute a configured Quick Action by name llt quickAction "Disable dGPU"

CLI Arguments Reference

Advanced startup arguments can be passed to Lenovo Legion Toolkit.exe directly or added to %LOCALAPPDATA%\LenovoLegionToolkit\args.txt (one argument per line):

Argument Description
--trace Enables verbose diagnostic logging to the log directory.
--minimized Starts the application directly minimized to the system tray.
--debug Enables debug mode and the embedded C# Script Console.
--skip-compat-check Bypasses startup model checks (used after motherboard replacements with unwritten serials).
--allow-all-power-modes-on-battery Allows selecting Performance and Custom modes while running on battery.
--force-disable-rgbkb Disables all 4-zone RGB keyboard communication.
--force-disable-spectrumkb Disables all Spectrum per-key RGB communication.
--force-disable-lenovolighting Disables logo, rear port, and white backlight controls.
--enable-lamp-array Enables Windows Dynamic Lighting integration for compatible keyboards.
--experimental-gpu-working-mode Switches GPU Working Mode logic to the LegionZone method.
--experimental-its-mode Enables experimental ITS mode driver for ThinkBook systems.
--disable-update-checker Disables built-in update checks (useful when managing updates via Scoop or WinGet).

Organization Repositories & Role in LLT

The LenovoLegionToolkit-Team organization maintains several focused open-source repositories that provide the underlying hardware abstractions, telemetry interfaces, and extension mechanisms for the main application.

LenovoLegionToolkit Main Desktop Application Host WPF application, user interface, Embedded Controller (EC) drivers, automation processor, and tray coordinator.
LenovoLegionToolkit-Plugins Modular Plugin Library Provides DLL-based extension interfaces allowing modular capabilities (such as custom fan curve extensions and integrations) without altering core codebase.
HarmonyBridge Runtime Method Patching Provides non-intrusive runtime method patching for advanced hook workflows and internal controller interception.
LibreHardwareMonitor Hardware Sensor Telemetry Specialized fork providing low-level hardware sensor polling for CPU, GPU, memory, and PCH temperatures, power limits, and fan RPM readouts.

PresentMonFps Frame Rate Metrics Engine Managed .NET wrapper for Intel PresentMon, capturing ETW presentation events to calculate real-time framerate and frame-time data for the On-Screen Display (OSD).
ZenStates-Core AMD Platform Control Low-level register interop library providing P-state and power state communication on AMD Ryzen based laptops.

Plugins & Extensibility

The toolkit supports a plugin architecture through the LenovoLegionToolkit-Plugins repository. Plugins are compiled as independent .dll assemblies placed in the application's plugin directory.

This modular architecture allows contributors to develop specialized fan curve algorithms, third-party lighting integrations, or custom hardware monitors without recompiling or destabilizing the core application.

Developing Plugins

Plugin development guidelines, interfaces, and sample implementations are maintained in the LenovoLegionToolkit-Plugins repository.

Security Alerts & Code Signing

Because Lenovo Legion Toolkit interacts directly with low-level Windows kernel drivers (WMI, EC register drivers, low-level keyboard hooks), generic antivirus scanners may occasionally produce false-positive heuristic alerts.

All official release builds:

  • Are built transparently from open source via public GitHub Actions runners.
  • Are cryptographically signed with an Authenticode project certificate.
  • Include full verifiable source code available for independent security audit.

Collecting Diagnostic Logs

When reporting issues or requesting compatibility investigation, diagnostic logs provide necessary hardware register outputs.

Enabling Logs via Settings (Standard Method)

  1. Open Settings.
  2. Toggle Enable logging.
  3. Reproduce the issue or hardware condition.
  4. Log files are saved to: %LOCALAPPDATA%\LenovoLegionToolkit\log

Startup Logging (For Startup Crashes)

  1. Ensure the application is completely closed and not in the system tray.
  2. Open the Windows Run dialog (Win + R).
  3. Execute: "%LOCALAPPDATA%\Programs\LenovoLegionToolkit\Lenovo Legion Toolkit.exe" --trace
  4. Reproduce the condition, close the app, and collect files from %LOCALAPPDATA%\LenovoLegionToolkit\log.
