# Lenovo Legion Toolkit - Official Website

Source files for the official Lenovo Legion Toolkit website:
https://lenovolegiontoolkit-team.github.io/

## Local Development

Open `index.html` in any web browser, or serve locally using a static server:

```bash
python -m http.server 8000
```

## Deployment

Changes pushed to the `main` branch of this repository automatically deploy to GitHub Pages:
https://github.com/LenovoLegionToolkit-Team/LenovoLegionToolkit-Team.github.io

## Structure

- `index.html`: Main landing page markup.
- `style.css`: Visual styles and layout definitions.
- `script.js`: Client-side release resolution and interface interactions.
- `assets/`: Static image resources and interface captures.
